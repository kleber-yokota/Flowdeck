web/graph — how each block type is represented

Each block type has its own shape. sequence draws boxes top → bottom; async draws boxes side by side (no arrow); if / else if / else are side by side, each with a down arrow to the next dependency; loop marks the box with a loop symbol; child and wait use distinct symbols. The outline color is the block level (a violet ramp L0→L2) — never the status, which keeps its own 4 colors.
