web/graph — how each block type is represented

Each block type has its own shape. sequence draws boxes in order; async stacks each box one below the last (no arrow); if / else if / else is a stack whose branches arrow to the next dependency; loop marks the box with a repeat symbol; child and wait use distinct symbols. The outline color is the block level (L0/L1/L2 metallic) — never the status, which keeps its own 4 colors. Sequence flows top → bottom.
