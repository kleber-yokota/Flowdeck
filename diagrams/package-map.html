The single queue contract: boot.Launch registers one queue (boot.QueueName) and dispatch (actions.Enqueue) and resume (actions.Resume) enqueue on it. core/boot/lifecycle.go · boot · dispatch.go · Enqueue · resume.go · Resume
Dispatch sanitization (form values → clean input, (Spec).Sanitize) lives in the web layer (catalog/executions) — the core's Enqueue receives only a clean payload. web/catalog/workflow.go · handleWorkflowPage · web/executions/dispatch.go · handleRunDispatch · core/graph/sanitize.go · (Spec).Sanitize
The executed path (the RunPath: state + steps) is a read model with the poll control — the state rides on the path so the poll knows when to stop (the Terminal rule). core/reads/steps.go · RunPath · Steps · core/status/state.go · (State).Terminal
Resume uses the SDK's ResumeWorkflow (the SDK resumes from the last completed step) — the pinned behavior is tested in the pause workflow (10s sleep). core/actions/resume.go · Resume · workflows/pause/pause.go · Pause · core/actions/resume_test.go
The detail page's input values come from the stored step arguments (the SDK stores the input per step) — the read model (ExecutionDetail) carries the values, not the raw payload. core/reads/detail.go · Detail · inputValues · inputOf
The retries-exhausted run is not resumable (the pinned SDK behavior — the pause test with WithMaxRecoveryAttempts(0); the failure is documented in bug.md). core/actions/resume_test.go · TestResumeOfFailedRun · workflows/pause/pause.go · pauseStep
The cancel is only for live runs (queued/running) — the guard (ErrNotCancellable) is in core; the DBOS cancel flips the row to CANCELLED and the ACK reads the row back. core/actions/cancel.go · Cancel · cancelAck · ErrNotCancellable
The dispatch ACK returns the queued row (id + state + created_at) — the badge's first execution date comes from the same read (reads.listByID). core/actions/dispatch.go · Enqueue · dispatch · core/reads/status.go · listByID
The child row on the executed path (the child kind) shows the child's name + the child's live badge (the ChildID lookup) — the row mapping (the batched child query) is shared with the detail read. core/reads/steps.go · RunPath · childIDsOf · childRows · childInfo · core/reads/detail.go · Detail
