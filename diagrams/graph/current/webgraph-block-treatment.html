web/graph — how it receives and treats the block model

core/graph produces the block model at boot (blocks · levels · types · nodes). web/graph receives it, then treats it (top → bottom): 1 receive, 2 assign the block level (violet ramp L0/L1/L2) to each block's outline, 3 represent each block type (sequence · join · if · loop) and node kind (async · child · wait), 4 compute the layout (positions · arrows · symbols · nesting by level), 5 emit the SVG (scale 1.25). The outline color is the level — never the status, which keeps its own 4 colors.
