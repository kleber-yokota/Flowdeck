Possible paths — blocks by level, stored as a tree

A possible-path is a tree of blocks, not a flat list of steps. Every block has a level (depth — the root is L0, a larger level is more internal), a type (sequence · loop · if), and ordered children. Independent blocks share a level (siblings) and run in order. The tree is stored, not recomputed. A simple workflow (only steps) is a single L0 block; the example below adds two sequential loops.
