Possible paths — blocks by level, stored as a tree

A possible-path is a tree of blocks, not a flat list of steps. Every block has a level (depth — the root is L0, a larger level is more internal; an if keeps the level of the block it appears in), a type (sequence · loop · if), and ordered children. A block can hold blocks and steps — a loop can contain an if, a step, or another loop — the nesting goes to n levels (unbounded). Independent blocks share a level (siblings) and run in order.
