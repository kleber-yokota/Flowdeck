web/graph — how it receives and treats the block model

core/graph produces the block model at boot (blocks · dependencies · levels · types). web/graph receives it, then treats it to build the graphic: 1 receive, 2 assign the 7-color rotation to each block's outline, 3 represent each block type (async · if · loop · sequence), 4 compute the layout (positions · arrows · symbols · nesting by level), 5 emit the SVG. The 7 colors cycle, so any number of blocks, levels and types stays visually clear.
