# core/board

The live read of the dashboard: `Live` (the three live boxes — the running runs · the queued runs · the failed workflows), `Living` (the running-runs list), `Queued` (the queued-runs list), `Failed` (the failed-workflows read). Observes durable state — nothing is executed here.

## Rules (decisions · pinned values)

- The live read: the running box counts the runs running right now and the queued box the runs in the queue right now (firing the same workflow several times counts each run — no deduplication by workflow); the failed box counts the workflows whose latest run is error ∪ cancelled · a latest success with no live run in no box · one `ListWorkflows` (`WithFilterSortDesc` · `LoadInput(false)` · `LoadOutput(false)`). *(evidence: `live.go · LiveCounts`)*
- The running-runs read: `Living` returns one row per running run (`LiveRun`: `Name` · `ID` · `State` · `CreatedAt` RFC3339) — no dedup by workflow name (two fires of the same workflow = two rows) · the SDK's desc order (newest first · no re-sort) · `State` is always `running` (the list filters to it) · not up → `boot.ErrNotLaunched` (the guard, like every other read). *(evidence: `living.go · LiveRun` · `Living`)*
- The queued-runs read: `Queued` returns one row per queued run (`LiveRun`: `Name` · `ID` · `State` · `CreatedAt` RFC3339) — `State` is always `queued` (the list filters to it: `ENQUEUED` ∪ `DELAYED`) · no dedup by workflow name · the SDK's desc order · not up → `boot.ErrNotLaunched` (the guard, like every other read). *(evidence: `queued.go · Queued` · `queued_test.go`)*
- The failed read: `Failed` returns one row per failed workflow (`FailedRun`: `Name` · `ID` · `State` · `CreatedAt` RFC3339 · `Message`) — a workflow is failed when its latest run is error ∪ cancelled (first row of the desc list · a latest success removes it) · the error `Message` is the row's `s.Error` (the step error · `s.Error.Error()`), batched into one `ListWorkflows` by the error-row ids with `WithFilterLoadOutput(true)` (the error column loads only with `LoadOutput(true)`), and the cancelled rows carry no message (`s.Error` is nil — no trace) · the SDK's desc order (no re-sort) · not up → `boot.ErrNotLaunched` (the guard, like every other read). *(evidence: `failed.go · FailedRun` · `Failed` · `failed_test.go`)*
- The state mapping is owned by `core/reads` (`MapState`) — the board reads map the SDK states through it (the edge: `core/board` → `core/reads`, one direction, to the owner). *(evidence: `live.go · bucketLive` · `failed.go · collectFailed` · `reads/status.go · MapState`)*
