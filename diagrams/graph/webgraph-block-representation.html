web/graph — how each block type is represented

Each block type has its own visual representation. sequence draws boxes in order; async stacks each box one below the last (no arrow); if / else if / else is a stack whose branches arrow to the next dependency; loop marks the box with a repeat symbol. child and wait use distinct box styles. Every box outline comes from the 7-color rotation, so blocks of any level or type stay visually clear.
