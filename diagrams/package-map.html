suites THE GREEN BASELINE

The unit and race suites are self-booting (a fresh per-test boot — no env · no -p 1); the e2e suite is env-driven (the DBOS_* env block · one shared boot · -p 1). Run them before and after a task; all three must be green.

suitecommandwhat it catches
unitgo test -count=1 ./...the green gate (no env · self-booting)
racego test -race -count=2 -shuffle=on ./...the green gate (no env · self-booting · race detector · shuffled · repeatable)
e2ethe env block (DBOS_APP_NAME=flowdeck_e2e · DBOS_SYSTEM_DATABASE_URL=sqlite:/tmp/flowdeck-e2e.db) + go test -tags e2e -run TestE2E -p 1 ./...launch · enqueue · poll · step rows · child rows · detail · resume · cancel · live
